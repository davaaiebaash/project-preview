# 📚 Neuropanda.ai Prompt Library

Локальная HTML-библиотека для хранения, поиска и быстрого копирования промптов.

## 📁 Содержимое

- `index.html` — автономное веб-приложение Neuropanda.ai Prompt Library.
- `form.html`, `style.css`, `script.js` — прежний генератор кейсов для портфолио, сохраненный в репозитории.
- `example-image.jpg` — демонстрационный визуал из исходного проекта.

## 🚀 Как использовать библиотеку

1. Откройте `index.html` в браузере.
2. Создайте раздел в левой панели.
3. Добавляйте промпты с тегами и примечаниями.
4. Используйте поиск, закрепление, дублирование и умные переменные.
5. Регулярно скачивайте JSON-бекап через кнопку «Скачать бекап базы».

## 🔐 Хранение данных

Приложение работает офлайн и хранит данные в `localStorage` текущего браузера. Телефон и компьютер не синхронизируются автоматически, поэтому переносите данные вручную через экспорт и импорт JSON-бекапа.
