# 🧩 Project Preview & Webform

Добро пожаловать в репозиторий визуальных кейсов и генератора портфолио.

## 📁 Содержимое

- `index.html` — шаблон обложки кейса (1280×720)
- `style.css` — стилизация обложки
- `preview/example-image.jpg` — образец визуала проекта
- `webform/` — форма генерации кейса с текстовой структурой

## 📄 Как использовать

### 🖼 Обложка проекта
🔗 [Открыть обложку проекта](https://davaaiebaash.github.io/project-preview/)

1. Замените изображение `example-image.jpg` на реальную обложку
2. Отредактируйте текст в `index.html` (название проекта, описание)
3. Сохраните как обложку в портфолио

---

### 📝 Генератор кейса
🔗 [Открыть форму](https://davaaiebaash.github.io/project-preview/webform/form.html)

1. Введите данные о проекте
2. Нажмите "Сгенерировать кейс"
3. Скопируйте текст и используйте в портфолио (например, на Freelance.ru)

---

## 🚀 Использование для портфолио

Можно добавлять новые папки:
preview/case-01/
preview/case-02/
И встраивать ссылки или изображения на эти обложки внутри `README.md` или `index.html`.
